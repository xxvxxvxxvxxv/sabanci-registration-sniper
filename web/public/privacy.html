Privacy

Plans and watch preferences are stored in this browser. There are no accounts, analytics scripts, or uploads of complete plans. Clearing site data deletes the local plan; export a backup in Settings.

Seat checks send the requested term and CRN to this site's server. The server caches public catalog and seat data, and requests it from Sutable and SUIS. Hosting providers receive ordinary connection metadata such as IP addresses and request paths. Counts are shared between visitors and include their observation time.

Optional Telegram alerts connect directly from this browser to Telegram. The bot token and chat identifier stay in tab session storage and are sent only to Telegram. Closing the tab removes these saved credentials in normal browsing; browser session recovery may restore session storage. Disconnect removes them explicitly. Default messages omit course details; detailed messages require an opt-in.

The site does not request SUIS credentials or submit registrations. Browser alerts and monitoring require an open tab and an awake device. A free seat is an observation, not a reservation or eligibility confirmation.

Unofficial student project. Catalog source: Sutable. Registration source: SUIS.

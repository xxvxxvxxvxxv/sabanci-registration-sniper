TELEGRAM NOTIFICATIONS

Alerts are sent when a watched section changes from full to available. Already-open seats and routine checks do not send messages. Default messages contain no course, CRN or timetable. Telegram receives the message and delivery metadata. Keep this tab open on an awake device.

  1. Create a personal bot using Telegram's @BotFather → /newbot.
  2. Paste its token below. The token stays in this tab’s session storage and is sent directly to Telegram, never to this site’s server. Disconnect removes the saved token. Browser session recovery may restore tab storage.

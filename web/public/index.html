CHROME DESKTOP · VERSION 0.9.0

From timetable to CRN fields.

Install once. Connect the planner. Preview and fill the registration form.

Download extension 0.9.0 ↓
01

Install

  1. Download the ZIP and extract it into a permanent folder.
  2. Open chrome://extensions in Chrome’s address bar.
  3. Enable Developer mode, choose Load unpacked, then select the folder containing manifest.json.

02

Connect the planner

  1. Select the sections in Timetable. Resolve any preparation errors under CRNs.
  2. On this website, open Chrome’s Extensions menu and select Registration Sniper.
  3. In its side panel, choose Use this website tab. Check the CRN list and keep the planner tab open. No connection key is needed.

The side panel stays beside the page when clicking elsewhere.

03

Preview → fill → review

  1. Sign into SUIS and open Add/Drop for the same semester.
  2. Choose Preview CRN fields. Check the semester and field mapping.
  3. Choose Fill & verify within 60 seconds. Review the filled form, then submit in SUIS manually.

After changing the plan or registration page, preview again.

Live form verification pending. Version 0.9 passes sample-form tests. An unfamiliar form or unverifiable semester stops autofill. The extension does not log in or submit registration.

AIMBOT / PREPARE MODE

React to the next opening.

Connect the planner and start its seat monitor. In the extension, select the SUIS Add/Drop tab with Use this SUIS tab, then enable Prepare on a new seat opening. When all selected CRNs have fresh available seats after a new opening, Registration Sniper navigates recognized Add/Drop steps and fills once.

Keep the source tab, side panel and device awake. Arming expires after 30 minutes. Login, session renewal and registration submission are manual until the live trial flow is verified.

Updating an existing installation

Extract the new download and replace the files in the installed extension folder. Open chrome://extensions, click the extension’s Reload button, and accept changed permissions if Chrome prompts. Reopen the side panel and reconnect this website tab.

“Term not available” or fields not recognized

Autofill needs the actual Add/Drop CRN form. A login page, a semester dropdown or a closed registration period has no CRN fields to fill. Use Copy CRNs for manual entry if the form is unsupported. Do not clear existing registration entries just to make autofill run.

What stays on this device?

The extension reads the prepared CRN list from the planner tab and fills recognized fields in SUIS. It does not collect the SUIS password. Major and credit-band preferences stay in browser storage.

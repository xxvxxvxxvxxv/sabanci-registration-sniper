# Publishing

Use [the Cloudflare deployment guide](docs/DEPLOYMENT.md) to publish the web version from GitHub. Source code remains on GitHub; the website and public feed run on Cloudflare.

The local Python application and extension remain available as an optional download. The Chrome extension currently supports the local mock registration form only. Publishing it in the Chrome Web Store requires the owner's developer account, listing assets and review; it is not published by this package.
